# 服务 500 排查手册

## 现象

客户端调用服务接口时收到 HTTP 500，表示服务端处理请求时发生内部错误。

## 排查步骤

1. 查看发生 500 的时间、请求路径和请求 ID，确定故障范围。
2. 根据时间和请求 ID 查询应用日志，找到对应异常堆栈。
3. 如果日志显示数据库连接失败，检查数据库服务状态和连接配置。
4. 如果日志显示 Redis 超时，检查 Redis 服务状态以及应用到 Redis 的连接。
5. 对比故障前后的部署、配置和依赖服务变化。
6. 修复原因后，用相同请求验证接口恢复，并观察后续错误日志。

## 需要记录的信息

记录故障时间、请求 ID、异常信息、影响范围、采取的处理措施和恢复结果。

# Redis 超时排查手册

## 现象

应用访问 Redis 时请求耗时升高或超时，依赖 Redis 的接口可能变慢或失败。

## 排查步骤

1. 确认故障发生时间、受影响的接口和应用实例。
2. 检查 Redis 服务是否正常运行，以及应用是否能连接 Redis 地址和端口。
3. 查看应用日志，确认是否出现 Redis 连接超时、读取超时或连接池耗尽。
4. 检查 Redis 当前连接数、内存使用量和慢查询情况，并与正常时段比较。
5. 检查应用连接池配置和近期的应用、Redis 配置变更。
6. 记录发现的异常指标和日志，再根据证据决定后续处理；没有证据时不要直接清空缓存或重启服务。

## 需要记录的信息

记录故障时间、受影响服务、Redis 错误日志、连接数和内存指标、近期变更及处理结果。
